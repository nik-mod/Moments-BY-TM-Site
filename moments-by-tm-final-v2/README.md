# Moments by TM

მობილურზე ორიენტირებული, სრულად responsive ფოტოგრაფის პორტფოლიო.

## ტექნოლოგიები
- HTML
- CSS
- JavaScript
- Tailwind CSS / `tailwind.config.js`

## გვერდები
- `index.html` — მთავარი
- `portfolio.html` — პორტფოლიო და ფილტრები
- `about.html` — ჩემ შესახებ
- `services.html` — სერვისები და ფასები
- `contact.html` — კონტაქტი / დაჯავშნა

## გაშვება
შეგიძლიათ პირდაპირ გახსნათ `index.html`. უკეთესი ლოკალური ტესტირებისთვის გაუშვით მარტივი local server პროექტის საქაღალდიდან, მაგალითად:

```bash
python -m http.server 8000
```

შემდეგ გახსენით `http://localhost:8000`.
